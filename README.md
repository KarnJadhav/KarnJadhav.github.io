# Karnsinh Jadhav — Portfolio

A responsive, static portfolio built with HTML and CSS, ready for GitHub Pages.

## Publish it for free

1. Sign in to GitHub as `KarnJadhav`.
2. Create a **public** repository named exactly `KarnJadhav.github.io`.
3. Upload `index.html` and `style.css` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then Save.
7. Wait for the Pages deployment to finish. Your expected site address is:
   https://karnjadhav.github.io/

GitHub's guide: https://docs.github.com/en/pages/quickstart
